# 🎬 Netflix Data Analysis Dashboard - Power BI

Este proyecto presenta un análisis exhaustivo del catálogo de Netflix, transformando datos crudos en un panel de control interactivo diseñado para la toma de decisiones estratégicas.

## 📊 Descripción Técnica y Complejidad
Para este dashboard, he aplicado técnicas de nivel avanzado para garantizar un informe profesional, escalable y visualmente impactante:

### 🧠 Modelado y Lógica DAX
* **KPIs Dinámicos:** Creación de medidas DAX para el recuento de títulos y países, optimizando el rendimiento frente al uso de columnas calculadas.
* **Análisis de Tendencias:** Implementación de lógicas temporales para visualizar el crecimiento del catálogo año tras año (2008-2021).
* **Limpieza de Datos (ETL):** Procesamiento en Power Query para normalizar nombres de directores, países y eliminar registros inconsistentes.

### 🛠️ Funcionalidades de Alto Nivel
* **Tooltips Personalizados:** Configuración de páginas de detalle ocultas que muestran información específica al interactuar con el Top 10 de Directores.
* **Experiencia de Usuario (UX/UI):** Diseño "Dark Mode" personalizado con segmentadores duales sincronizados para una navegación fluida entre tipos de contenido (Movie/TV Show).
* **Diseño de Lienzo:** Ajuste milimétrico del papel tapiz y transparencias para lograr una estética fiel a la identidad de marca de Netflix.
